# منصة مصطفى حسام | مهندس الماث

نسخة React (Vite + Tailwind CSS) مبنية على هيكل موقع mr-mostafa-hossam.com الفعلي
(بعد تحليل الـ DOM الحقيقي للموقع). البنية والـ copy الأساسي مطابقين للموقع الأصلي،
والصور استبدلتها بـ placeholder لحد ما تديني الصور الحقيقية.

## الأقسام المطابقة للموقع الأصلي

- **Navbar**: لوجو + زرار "انشاء حساب" + زرار "سجل دخولك" + تبديل الوضع الليلي/النهاري
- **Hero**: "مهندس الماث / م. مصطفى حسام" + الوصف + زرار "انضم لعيلة المهندس"
- **جميع المراحل الدراسية**: تابس (كل المراحل / إعدادي / ثانوي) + ٦ كروت للسنين الدراسية
  بألوان مختلفة لكل مرحلة
- **ليه تختار مهندس الماث**: ٣ كروت بزوايا غير متماثلة (فيديوهات / متابعة ودعم / امتحانات)
- **Footer**: لوجو + وصف + روابط سوشيال ميديا + CTA "جه وقت البداية" + بيانات المطور
- **زرار واتساب عائم**

## ناقص وعايز منك تكمله

1. **الصور الحقيقية**: صورة المدرس في الـ Hero، صور الـ ٦ سنين الدراسية، اللوجو.
   حاليًا كلها placeholder ملون.
2. **أيقونات السوشيال ميديا**: حاليًا دوائر بحروف (YT, TT, TG, FB) بدل اللوجوهات
   الحقيقية — تقدر تحطلي أيقونات SVG حقيقية.
3. **رابط الواتساب ورقم التواصل**: حط رقمك الفعلي في `WhatsAppButton.jsx`.
4. **صفحات فرعية**: /register, /login, /years/:id — مش موجودة في النسخة دي،
   المشروع حاليًا صفحة رئيسية واحدة (Landing Page). لو عايزها كاملة بنظام
   تسجيل دخول وصفحات كورسات فعلية، قولي وهنتكلم على الـ backend المطلوب.
5. **الألوان**: قريت الألوان من كود الموقع (dodger blue + أخضر #47C780 + كحلي
   #043B70) لكن مفيش عندي القيم الدقيقة 100% لكل درجات اللون، لو عندك ملف
   الألوان الأصلي (design tokens) ابعتهولي.
